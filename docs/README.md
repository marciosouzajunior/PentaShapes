# Documentação

O PentaShapes reúne prática guiada de improvisação, exemplos sonoros e diagramas do instrumento. Esta documentação descreve a estrutura atual e as orientações para contribuir.

| Documento | Conteúdo |
| --- | --- |
| [Arquitetura e desenvolvimento](arquitetura.md) | Módulos, execução, testes e publicação. |
| [Missões e leitura de estudo](missoes.md) | Experiência compartilhada de Preparar e Tocar, direção visual dos esboços e critérios de revisão. |
| [Tom de voz](tom-de-voz.md) | Escrita da interface e do conteúdo didático. |
| [Catálogo e autoria](catalogo-e-autoria.md) | Contrato de trilhas, identidade, progresso e evolução do catálogo. |
| [Referências musicais](referencias-musicais.md) | Princípios usados no conteúdo, fontes e limites de interpretação. |
| [Curadoria de Purple Haze](curadoria-purple-haze.md) | Proveniência dos eventos, adaptações e revisão musical. |

Para contribuir com uma trilha, comece pelo modelo de missões e pelo contrato de autoria. Código e conteúdo devem passar pelas verificações descritas em arquitetura. Licenças e créditos estão no [aviso de terceiros](../THIRD_PARTY_NOTICES.md).
